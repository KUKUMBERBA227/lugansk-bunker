# ЛУГАНСК БУНКЕР

Статический сайт на Vite + Leaflet для публикации на Vercel.

## Что умеет
- Интерактивная карта OpenStreetMap с центром на Луганске.
- Ссылки на официальные информационные ресурсы России и ЛНР.
- Адаптивная тёмная тема, часы и ручное обновление информационного блока.
- Не показывает неподтверждённый статус тревоги: у перечисленных официальных ресурсов не заявлен доступный публичный API для автоматического статуса.

## Источники
- Главное управление МЧС России по Луганской Народной Республике: https://81.mchs.gov.ru/
- Оперативная информация МЧС: https://81.mchs.gov.ru/deyatelnost/press-centr/operativnaya-informaciya/vnimanie
- Правительство ЛНР: https://sovminlnr.ru/
- Карта: OpenStreetMap.

Сайт не является официальной системой оповещения. Не полагайтесь на него как на единственный источник информации; следуйте указаниям экстренных служб.

## Запуск локально
Требуется Node.js 20+.

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Публикация на Vercel
1. Загрузи содержимое папки в GitHub-репозиторий.
2. Импортируй репозиторий на https://vercel.com/new.
3. Build command: `npm run build`; Output directory: `dist`.
4. Нажми Deploy.
